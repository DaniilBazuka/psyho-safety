## 1️⃣ **cd** (Change Directory) — Переход в папку

### 🔍 Что делает:

Меняет текущую рабочую директорию.
## Синтаксис

```
1. cd [путь_к_папке]
```
## Пример

```
1. # Перейти в конкретную папку
2. cd /home/user/documents
3. 
4. # Перейти на уровень вверх
5. cd ..
6. 
7. # Перейти в домашнюю директорию
8. cd ~
9. # или просто
10. cd
11.
11. # Перейти в предыдущую папку
12. cd -
14.
15..# Перейти на два уровня вверх
16..cd ../..
```

## 2️⃣ **mkdir** (Make Directory) — Создание папки

### 🔍 Что делает:

Создаёт новую директорию (папку).
## Синтаксис

```
mkdir [имя_папки]
mkdir -p [путь/с/несколькими/папками]
```
## Пример

```
# Создать одну папку
mkdir my_folder

# Создать несколько папок сразу
mkdir folder1 folder2 folder3

# Создать вложенные папки (ключ -p)
mkdir -p project/src/utils
# Создаст: project → src → utils

# Создать папку с правами доступа
mkdir -m 755 secure_folder
```

## 3️⃣ **rm** (Remove) — Удаление файлов и папок

### 🔍 Что делает:

Удаляет файлы и директории.
## Синтаксис

```
rm [файл]           # Удалить файл
rm -rf [папка]      # Удалить папку рекурсивно
```
## Пример

```
# Удалить файл
rm file.txt

# Удалить несколько файлов
rm file1.txt file2.txt

# Удалить пустую папку
rmdir empty_folder
# или
rm -d empty_folder

# Удалить папку со всем содержимым (ОСТОРОЖНО!)
rm -rf my_folder

# Удаление с подтверждением
rm -i important.txt
# Спросит: remove 'important.txt'? y/n

# Удалить все .txt файлы в папке
rm *.txt
```

##  ⚠️==**Важные флаги !!!**==

- ==`-r`== (recursive) — рекурсивное удаление папок
- ==`-f`== (force) — без подтверждения (форсировать)
- ==`-i`== (interactive) — спрашивать подтверждение

## 4️⃣ **nano / vim** — Редакторы текста в терминале

### 🔍 Что делают:

Открывают файлы для редактирования прямо в консоли.

### Nano (простой редактор):

```
1. nano file.txt
```

- ==`Ctrl+O`== → Сохранить (Write Out)
- ==`Ctrl+X`== → Выйти (Exit)
- ==`Ctrl+K`== → Вырезать строку
- ==`Ctrl+U`== → Вставить строку
### Vim (мощный редактор):

```
1. vim file.txt
```

**Основные команды vim:**

- ==`i`== → Войти в режим вставки (Insert)
- ==`Esc`== → Выйти в нормальный режим
- ==`:w`== → Сохранить
- ==`:q`== → Выйти
- ==`:wq`==  → Сохранить и выйти
- ==`:q!`==  → Выйти без сохранения

## Пример

```
1. # Создайте файл с текстом
2. nano hello.txt
3. # Введите: "Привет, мир!"
4. # Нажмите Ctrl+O, Enter, Ctrl+X
5. 
6. # Проверьте
7. cat hello.txt
```
## 5️⃣ **touch** — Создание пустых файлов

### 🔍 Что делает:

Создаёт пустой файл или обновляет временную метку существующего.

## Синтаксис:

```
1. touch [имя_файла]
```

## Примеры

```
# Создать один файл
touch newfile.txt

# Создать несколько файлов
touch file1.txt file2.txt file3.txt

# Создать файл в папке
touch folder/newfile.txt

# Создать файлы с расширением
touch script.py config.json data.csv

# Обновить время файла (если существует)
touch existing_file.txt
```

## 6️⃣ **chmod** (Change Mode) — Изменение прав доступа

## 🔍 Что делает:

Меняет права доступа к файлам и папкам.
## 📝 Права доступа:

- **r** (read) = 4 → Чтение
- **w** (write) = 2 → Запись
- **x** (execute) = 1 → Выполнение
## Синтаксис

```
1. chmod [права] [файл]
```
## Пример 

#### Цифровой способ:

```
1. # 755: владелец (чтение+запись+выполнение), остальные (чтение+выполнение)
2. chmod 755 script.sh
3. # rwxr-xr-x
4. 
5. # 644: владелец (чтение+запись), остальные (только чтение)
6. chmod 644 file.txt
7. # rw-r--r--
8. 
9. # 777: все имеют все права (НЕ БЕЗОПАСНО!)
10. chmod 777 dangerous.txt
11. 
12. # 600: только владелец читает и пишет
13. chmod 600 secret.txt
```
#### Буквенный способ:

```
1. # Добавить право на выполнение для всех
2. chmod +x script.sh
3. 
4. # Убрать право записи у группы и остальных
5. chmod go-w file.txt
6. 
7. # Дать владельцу все права
8. chmod u+rwx file.txt
```
